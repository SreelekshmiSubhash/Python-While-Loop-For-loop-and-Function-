#  Python Assignment 3 – Loops & Functions

## Overview
This work is part of my Python learning journey in AI-Driven Data Analytics. It focuses on implementing `while` loops, `for` loops, and user-defined functions through simple interactive programs.

## Learning Objectives
- Understand the working of while and for loops.
- Apply control statements such as `break`, `continue`, and `else`.
- Create and use user-defined functions.
- Practice user input, conditional logic, and basic calculations.

## Tasks Completed

### 1. While Loop – Number Guessing Game
- Developed a number guessing game using the `while` loop.
- Used conditional statements to provide hints such as Too High and Too Low.
- Implemented limited attempts and control statements.

### 2. For Loop – Multiplication Table Generator
- Created a program to generate the multiplication table of a user-entered number.
- Used a `for` loop and range function to iterate from 1 to 10.

### 3. Functions – BMI Calculator
- Created a user-defined function to calculate Body Mass Index (BMI).
- Used function parameters, return values, and user inputs.
- Formatted the calculated BMI to two decimal places.
